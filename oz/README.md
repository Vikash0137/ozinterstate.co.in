# MoveLink — Interstate Removalists Website

A premium, high-converting React JS website for an Australian interstate removalist company.

## Tech Stack

- **React 18** + **Vite**
- **Tailwind CSS** (custom blue & white logistics theme)
- **Framer Motion** (animations & page transitions)
- **Lucide React** + **React Icons**
- **React Router DOM** (multi-page routing)

## Pages

`Home` · `Company Profile` · `Our Services` · `Reviews` · `Our Blogs` · `Sitemap` · `Contact Us`

## Getting Started

```bash
npm install
npm run dev      # start dev server (http://localhost:5173)
npm run build    # production build
npm run preview  # preview production build
```

## Project Structure

```
src/
  components/    # Reusable UI (Header, Hero, QuoteForm, Stats, Services, ...)
  pages/         # Route-level pages
  data/          # Centralised dummy content (siteData.js)
  utils/         # Framer Motion variants
  index.css      # Tailwind + design system utilities
```
